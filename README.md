# Syntax Cam
Live-effect Android camera. Effects: TIME, TILES, CONFETTI, STENCIL. MIN–MAX intensity slider, shuffle (new random layout), front/back flip, save to Pictures/SyntaxCam.

## Release
```
git init && git add . && git commit -m "init"
git remote add origin https://github.com/<you>/SyntaxCam.git
git push -u origin main
git tag v1.0.0 && git push origin v1.0.0
```
GitHub Actions builds `SyntaxCam.apk` and attaches it to the release.
